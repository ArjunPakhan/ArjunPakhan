## Why it looks like this

The contribution graph above is a **neural metaphor applied to contribution data** — a network of nodes that fire and settle, not a dashboard.

- **Graphite** — a dormant day (no contribution that day)
- **Cyan-white** — the firing flash when a day activates
- **Plum** — the resting/strengthened state: active days settle into a glow brighter than dormant, weighted by contribution intensity and recency. This residual trace — the neuroplasticity effect — is what makes it read as a network with memory rather than a recolored graph.

One chronological sweep moves left to right; dense weeks wash the grid with a soft violet; the whole network resolves and breathes once before resetting. It's a metaphor for how systems (and people) accumulate and hold state over time — no streak counters, badge walls, or skill grids.
