## Why it looks like this

The contribution graph above is rendered as a cultured neuronal network (fluorescence microscopy, not a dashboard). 

- **Green** — living neural structure (dendrites, resting axons)
- **Coral** — active firing
- **Violet** — neuroplasticity / residual memory (strengthened pathways)
- **White** — electrical impulse travelling along an axon → terminal → dendrite → soma

Culture growth: dormant → outgrowth → contact → network formation → electrical activity → violet memory. The network visual *is* the data visualization — no streak counters, badge walls, or skill grids.

Interests: AI security, governance, systems thinking, building, research and behavioral science of how systems (and people) behave under constraints.
